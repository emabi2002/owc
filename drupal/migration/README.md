# OWC Drupal content migration

`content-export.json` is generated by `bun run drupal:export-content` and is intentionally not the authoritative source by itself. It is a canonical transport document between the transitional OWC content source and Drupal.

When privileged Supabase server credentials are present, the exporter reads the editorial tables using the service-role key. When they are absent, it generates the repeatable repository-reference dataset used by clean-room CI.

The Drupal importer is idempotent. Every canonical natural key maps to a deterministic UUID, so rerunning the same payload updates or skips an existing node rather than creating a duplicate.

Claims, claimant evidence, staff identities, CPPS data and operational audit records are excluded from this migration.
